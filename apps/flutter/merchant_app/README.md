# Botlly Merchant Flutter App

Cross-platform Flutter merchant app for Botlly marketplace. The same Dart codebase is used for Android and iOS, with platform files generated by Flutter stable during CI.

## Features

- Merchant login and signup.
- Merchant dashboard with products, orders, and store completion.
- Product create, edit, delete, image upload, and currency selection.
- Store profile management.
- Arabic, English, and Sorani Kurdish UI strings.
- Backend connection through the same web API used by the website.

## Local Run

```bash
cd apps/flutter/merchant_app
flutter pub get
flutter run --dart-define=BOTLLY_API_BASE_URL=https://bot-lly.tech
```

## Platform Generation

The repository keeps the Flutter app source small and generates native folders in CI:

```bash
flutter create --platforms=android,ios --org tech.botlly .
python tool/configure_platforms.py
flutter pub get
```

`tool/configure_platforms.py` applies the native settings required by the app:

- Android internet, camera, storage/image, and notification permissions.
- iOS camera, photo library, notification permission descriptions.
- iOS WhatsApp and WhatsApp Business URL schemes.
- iOS notification entitlement and minimum deployment target.
- iOS bundle identifier `tech.botlly.merchant`.

## Backend

The mobile app talks to the website backend endpoint:

```text
POST /api/merchant/mobile
```

Supabase access stays behind the website backend, so Android and iOS use the same API contract and do not need separate Supabase client configuration inside the app.

## Builds

Android and iOS builds are handled by GitHub Actions:

- `.github/workflows/flutter-merchant-android.yml`
- `.github/workflows/flutter-merchant-ios.yml`

See `MOBILE_BUILDS.md` for install artifacts and App Store preparation notes.
